# Call of Duty 3: textures that show Nazi party or German military insignia.
#
# To replace one with your own picture, save a PNG named <file>.png (the first
# column, exactly, "$" and all) in <game folder>/data/cod3/user_textures_png/
# and press "Build user texture pack" in the setup tool (Play tab). The rules
# (PNG, RGBA 8-bit, the same aspect ratio, sizes, alpha) are in
# docs/TEXTURE_REPLACEMENT.md. Start from the ripped original,
# data/cod3/textures/<file>.png, so the picture lines up with the model.
#
# Columns (tab-separated):
#   file    the PNG name (without .png) of the ripped picture to replace
#   key     the texture's key (hd_keys.tsv): XXH64 of its original data. This,
#           not a memory address, identifies it while the game runs.
#   width, height   the original's size in texels
#   format  the GPU format the game keeps it in (DXT1, DXT3, DXT5)
#   sizes   sizes your PNG may have (any scale >= 1 with this aspect ratio,
#           sides multiples of 4, at most 8192; these are the whole scales)
#   alpha   "opaque": your PNG's alpha is ignored. "transparent parts": your
#           picture may be more solid than the original, never more see-through.
#   mp      whether your replacement is also used in a multiplayer match.
#           "no" for textures soldiers or vehicles wear: a replaced copy could
#           make players easier to see, so matches use the game's own.
#   kind    party: a Nazi party symbol (swastika, SS runes, party eagle).
#           military: a German military marking (Balkenkreuz, Iron Cross),
#           not a party symbol. related: Nazi-era, no party symbol visible.
#   shows   what the picture shows
#   where   the archives (sp/<level>/<archive>.cod, or sp/frontend.cod for the
#           menus) it is in
#
# This list covers the archives the list was made from: Saint-Lo (the first
# level, sp/saint_lo/*.cod), the shared sp/global.cod and sp/anim.cod, and the
# menus (sp/frontend.cod). Other levels reuse many of these (the same key);
# textures new to them are not listed yet. Movies (attract.wmv ...) are video,
# not textures, and can't be replaced this way; the animated menu background
# frames in frontend.cod's DTEX section aren't textures the game looks up
# either.
#
