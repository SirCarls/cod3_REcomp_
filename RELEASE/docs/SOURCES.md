# Sources

Where every piece of knowledge, code idea and download in this project comes from.

**How to read this list:**

- **A source** is linked, with the exact version, commit or file used where that matters, and what was taken from it and where it is used in this project.
- **Found by us** means we worked it out ourselves by examining a retail copy of the game (disassembly, decompressing files, comparing with the running game). [Section 10](#10-how-facts-are-verified) says how such facts are checked.
- **Dates** are when the source was used or a download was pinned.

No game data from any source is included in this project.

| **Found by us (2026-10-16)**, the SDK's Vulkan texture bindings (same commit, `src/graphics/vulkan/command_processor.cpp`, `UpdateBindings`) | Every draw allocated and wrote a new descriptor set for its textures and samplers (the code's own TODO: "Reuse texture and sampler bindings if not changed"); on the owner's PC `vkUpdateDescriptorSets` called from there was 5.2% of the GPU emulation thread. ## 10. How facts are verified

- **Addresses:** each one is checked in the disassembly of the exact supported build. The setup tool refuses any other build (the SHA-1 above).
- **Facts from the reference recomp:** re-checked against our own disassembly before use (for example the setjmp and longjmp prologues).
- **File formats found by us:** every rule is checked over a whole retail disc by `rip cod3-check` (also run by `tools/run_local.sh check`).
- **Fixes taken from Xenia Canary:** ported line for line, and the commit or PR is named next to the change.
- **Pinned downloads:** the hash or signature source is listed in [section 2](#2-downloads-the-setup-tool-pins).
- **Game behavior:** title screen and loading in the Claude session's software-GPU test; anything in a level on a real GPU by the owner. Results go into [REQUIREMENTS.md](REQUIREMENTS.md).
- **Thread and machine facts:** the profiler's numbers are checked on the Claude session's test machine (2 CPUs, software GPU) and against the owner's logs; the Windows code is compiled with MinGW but not yet run on Windows.
